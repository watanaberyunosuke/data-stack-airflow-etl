## dbt Healthcare Models

This dbt project standardises raw healthcare operational data generated by the seeding module. The current raw layer models patient records, medication catalogue entries, dispensing transactions, healthcare partner feeds, and care access channels.

### Typical commands

Try running the following commands:
- dbt run
- dbt test

### Modeling intent

- `raw.customers`: patient master data
- `raw.products`: medication catalogue by city
- `raw.transactions`: dispensing and fulfilment events
- `raw.resellers`: partner clinic and pharmacy organisations
- `raw.resellerscsv` and `staging.resellersxmlextracted`: external partner daily feeds
